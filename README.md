# 🚀 RentTech – Tech Product Rental Application

RentTech is a Flutter-based mobile application that allows users to rent electronic products such as laptops, smartphones, and accessories at an affordable price instead of buying them outright. The app focuses on ease of use, clean UI, and a smart rental flow, making tech accessible without heavy upfront costs.

---

## 📱 Key Features

- 🔐 User Authentication (Firebase Auth)
- 🏠 Home Dashboard with featured products & categories
- 🗂️ Product Categories (Laptops, Mobiles, Accessories, etc.)
- 📦 Product Rental Flow
    - Select rental duration
    - View rent, discount & refundable deposit
- 🛒 Cart & Orders Management
- 📍 Delivery Address Management
- 🤖 AI Chatbot (Google Gemini 1.5 Flash)
    - AI-generated responses (no predefined answers)
- 🔔 Notifications Module
- 👤 Profile Management
- 🧾 Order Status Tracking
    - Ongoing
    - Completed
    - Cancelled
- 🎨 Modern & Responsive UI
- 🧪 Beta Release Ready

---

## 🤖 AI Integration

RentTech uses Google Gemini 1.5 Flash to power its AI chatbot feature.

The chatbot helps users by:
- Answering product-related queries
- Assisting with the rental process
- Providing instant AI-generated responses

⚠️ Note: The AI feature is currently in beta and will be enhanced in future updates.

---

## 🛠️ Tech Stack

- Frontend: Flutter (Dart)
- Backend: Firebase
    - Firebase Authentication
    - Cloud Firestore
- AI Service: Google Gemini 1.5 Flash
- Animations: Lottie
- State Management: setState
